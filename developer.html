Developer Documentation

Complete technical reference for Web Development Mastery

Welcome to the official hub-level documentation for the Web Development Mastery platform. This guide provides comprehensive architectural details, deployment strategies, core system functionalities, and guidelines for contributing.

The platform encompasses multiple modules including HTML, CSS, JavaScript, and React, bound together by a unified, glassmorphic design language and state management system.

Architecture Overview

The Web Development Mastery platform is built on a highly modular, decoupled architecture, allowing each course module to function completely offline while maintaining global state synchronization via the localStorage API.

Getting Started

To run the platform locally, you simply need a modern web browser. The entire platform is built with vanilla web technologies and supports the file:// protocol seamlessly.

  1. Clone the repository: git clone https://github.com/Sanskar-in/Web-Development-Mastery.git
  2. Navigate to the folder: cd Web-Development-Mastery
  3. Open Hub: Double-click index.html in the root directory.

Local Server (Optional)

For advanced features like fetch API requests (if extended), use a local server like Live Server in VS Code.

File:// Protocol

Fully supported. localStorage works perfectly under file:// in modern browsers (Chrome, Edge, Firefox).

Core Architecture

Single-File Module Pattern

Each module primarily relies on an index.html file with inline or co-located CSS/JS. This ensures high portability and ultra-fast load times.

State Management (localStorage)

We use a namespaced approach to prevent collisions. Hub settings use hubMasteryTheme, while modules use htmlMastery_data, reactMastery_data, etc.

LocalStorage Implementation 
const HUB_THEME_KEY = 'hubMasteryTheme';

function saveHubTheme(theme) {
    localStorage.setItem(HUB_THEME_KEY, theme);
    document.documentElement.setAttribute('data-theme', theme);
}

function initHubTheme() {
    const saved = localStorage.getItem(HUB_THEME_KEY);
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    const theme = saved || (prefersDark ? 'dark' : 'light');
    saveHubTheme(theme);
}

Theme System

The platform boasts a robust CSS variables architecture. The hub controls light/dark modes, while individual modules may offer up to 25+ unique themes.

  • CSS Variables: All colors are defined in the :root selector and mapped to semantic names (e.g., --bg-color, --text-primary).
  • Glassmorphism: Achieved using backdrop-filter: blur(12px) and semi-transparent RGBA backgrounds.
  • Theme Switching API: Simple DOM manipulation flipping the data-theme attribute on the <html> element.

Quiz & Assessment System

Modules contain integrated assessment engines. Questions are stored in JSON format, randomized, and scored client-side. Progress is immediately persisted to localStorage.

Translation System

The platform implements an integrated Google Translate widget, enabling localization in 75+ languages globally.

Advanced modules may implement direct translation engines via XHR/Fetch depending on the target audience requirements.

Mastery Center

An integrated gamification system that tracks user progress across all modules.

  • XP System: Earn points by completing sections, passing quizzes, and consistent daily streaks.
  • Achievements: Unlock badges for milestones (e.g., "First Module Complete", "Quiz Master").

Code Examples & Snippets

All modules include rich code editors and snippet displays. We use standard <pre><code> blocks styled with custom syntax highlighting classes to ensure zero external dependencies.

Testing & QA Guide

Ensure the following checklist is met before pushing updates:

  1. Verify localStorage state doesn't throw quotas exceeded errors.
  2. Test responsive design on mobile (iPhone SE), tablet (iPad), and 4K displays.
  3. Validate file:// protocol execution (no CORS issues).
  4. Check contrast ratios for accessibility in both light and dark themes.

Deployment Guide

The platform is a static site. Recommended deployment targets:

  • GitHub Pages: Direct deployment from the main branch.
  • Vercel / Netlify: Drop the folder structure and let it auto-deploy.
  • Offline Distribution: Zip the folder and distribute (works perfectly).

Troubleshooting

Storage Quota

If localStorage is full, run localStorage.clear() in the console. Note: this resets all user progress.

Icons not loading

Ensure internet connection is active, as FontAwesome is loaded via CDN.

Contributing Guidelines

We welcome contributions! Please adhere to the following rules:

  • Maintain the pure HTML/CSS/JS architecture. Do not introduce build steps or Node.js dependencies for the core hub.
  • Use semantic HTML5 tags.
  • Ensure all new UI components are glassmorphic and support data-theme="dark" and "light".
