Frequently Asked Questions

Find quick answers to the most common questions about the Web Development Mastery platform and modules.

What is Web Development Mastery?
Web Development Mastery is a comprehensive, interactive learning platform designed by Sanskar Yadav. It covers fundamental and advanced topics across multiple modules including HTML, CSS, JavaScript, and React, aiming to provide a seamless, premium learning experience.
Is this platform free to use?
Yes! The core platform and all of its educational modules are completely free to use. We believe in accessible education for everyone. If you find the project helpful, you can optionally support it via the Donate section.
How do I navigate between modules?
You can navigate via the Hub Home. Simply click the "Hub Home" button in the navigation bar to return to the root dashboard, where you can select any available module (HTML, CSS, JS, etc.).
How does the theme system work?
The platform features a global Light/Dark mode toggle located in the top-right corner of the navigation bar. Your theme preference is saved in your browser's local storage and automatically applies across all modules.
How do I track my progress?
Progress tracking is built into specific modules. When you complete lessons, quizzes, or interactive exercises, your progress is automatically saved to your browser's local storage. This ensures you can pick up exactly where you left off.
Can I use this platform offline?
Once the pages and assets are loaded in your browser, many interactive components will continue to work offline. However, for the initial load, external resources like Google Fonts, and embedded videos, an active internet connection is required.
How do I report bugs?
You can report bugs by opening an issue on our GitHub repository. Please include clear steps to reproduce the issue, your browser version, and any relevant screenshots. Scroll down to the "Report a Bug" section for a direct link.
Is this open source?
Yes! The entire project is open-source and hosted on GitHub. We welcome contributions, feedback, and forks from the developer community. Check out our GitHub repository to view the source code.
How can I support the project?
You can support the project in several ways: star the repository on GitHub, share it with your friends and colleagues, report bugs, contribute code, or make a donation via the 'Support Project' button below.
Which browsers are supported?
The platform is optimized for modern web browsers. We officially support the latest versions of Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge. Internet Explorer is not supported.
How do I reset my progress?
To reset your progress, you need to clear your browser's Local Storage for this site. In most browsers, you can do this by opening Developer Tools (F12) > Application tab > Local Storage, and clearing the data.
Can I contribute to the project?
Absolutely! We welcome pull requests for bug fixes, new features, and content improvements. Please check our GitHub repository for the contribution guidelines and open issues you can tackle.

How to Report a Bug

  1. Check existing issues: Ensure the bug hasn't already been reported in the GitHub repository.
  2. Gather info: Note your browser version, OS, and exact steps to reproduce the error.
  3. Take screenshots: If it's a visual glitch, capture the screen or open Developer Tools (F12) to capture console errors.
  4. Open an issue: Click the button below to submit a detailed bug report on GitHub.

Common Issues

Platform looks broken / CSS not loading

Perform a hard refresh (Ctrl + F5 or Cmd + Shift + R) to clear the browser cache and load the latest stylesheets.

Progress not saving

Ensure your browser is not in Incognito/Private mode, and that you haven't disabled Local Storage or Cookies for this site.

Videos or External Links blocked

Check if you have an aggressive adblocker or tracking prevention enabled. Whitelist the domain to ensure full functionality.
